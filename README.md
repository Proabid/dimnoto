# Dimnoto

Public support and privacy pages for the Dimnoto iPhone app, in English and Swedish.

- [Support](https://proabid.github.io/dimnoto/support.html)
- [Privacy Policy / Integritetspolicy](https://proabid.github.io/dimnoto/privacy.html)

Contact: ettavett@gmail.com

## Files

- `index.html` — website entry page.
- `support.html` and `privacy.html` — published pages with English and Swedish sections.
- `support.md` and `privacy.md` — editable Markdown copies of the text. Keep these aligned with the HTML when updating the policy or support information.
- `icon.png` — Dimnoto app icon.
- `.nojekyll` — serves static files without Jekyll processing.

GitHub Pages uses the root of the `main` branch. The pages have no JavaScript, analytics scripts, external fonts or build dependencies. GitHub's own hosting logs are described in the privacy policy.
